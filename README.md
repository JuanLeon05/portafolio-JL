## Proyectos Destacados (High-Performance)

### 1. BattleBot Autónomo (STM32)
*Vehículo de competencia omnidireccional y combate.*
* **Tech:** Arquitectura Dual **STM32** (Blue Pill), C++ (HAL), FreeRTOS.
* **Hardware:** Cañón neumático (CO2 + Solenoides), Ruedas Mecanum, Sistema térmico (800°C).
* **Ingeniería:** Gestión de baterías LiPo, reguladores de voltaje y telemetría Bluetooth.

### 2. UAV Teknofest Turquía 2025
*Desarrollo de dron autónomo para competencia internacional.*
* **IA & Visión:** **NVIDIA Jetson Nano**, Python, OpenCV (Reconocimiento de objetivos).
* **Hardware:** Diseño de PCB de potencia personalizada, manufactura en fibra de carbono.

### 3. SpectraGlove (Wearable DSP)
*Guante háptico para visualización de audio en tiempo real.*
* **Procesamiento:** **Arduino R4 WiFi** (Renesas), Algoritmo FFT.
* **Innovación:** Latencia cero (<20ms) e integración en circuitos textiles flexibles.
