# Práctica 3: Bordado y Estampado
{: .fs-9 }

**Fundamentos de Manufactura Textil**
{: .fs-6 .fw-300 }

Antes de integrar hardware complejo en prendas de vestir, es fundamental comprender las propiedades mecánicas y los métodos de intervención sobre los sustratos textiles. Esta práctica documenta el aprendizaje de técnicas manuales y semi-industriales de modificación de telas.

El objetivo fue familiarizarse con la tensión del hilo, la resistencia de las tramas y el comportamiento de las tintas, habilidades cruciales para el posterior enrutamiento de hilos conductivos y el diseño estético de wearables.
