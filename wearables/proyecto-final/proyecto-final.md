# Proyecto Final: Melody Key
{: .fs-9 }

**Mangas Interactivas para el Aprendizaje Musical**
{: .fs-6 .fw-300 }

Melody Key es un sistema wearable compuesto por dos mangas instrumentadas (Maestra y Esclava) diseñado para asistir en el aprendizaje del piano. Mediante estímulos visuales (LEDs) y retroalimentación háptica, el sistema guía al usuario a través de partituras pre-programadas, traduciendo la notación musical tradicional en instrucciones físicas directas sobre las manos del intérprete.
